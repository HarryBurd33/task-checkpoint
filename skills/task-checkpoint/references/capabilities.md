# Capability matrix and evidence boundaries

| Capability | Requirements and limits in 0.7.0 |
|---|---|
| Manual save/verify | Python 3.9+, Git, writable workspace and an initial commit; no model required |
| Root handoff | Enabled output and intact managed markers; unrelated text preserved |
| Explicit resume | Current user instruction, verified files, fresh review/resources and exclusive lease |
| Automatic enrollment | Account opt-in and exclusions, delivered SessionStart/PreToolUse, stable host chat identity, eligible committed Git root; no semantic invention, lease acquisition or scheduled implementation |
| Chat isolation | Exact reviewed owning/unrelated IDs and native root-chat session_id (including subagent hooks), or explicit event thread_id when absent; conflicting fields fail closed, inherited CODEX_THREAD_ID ignored, unknown IDs and legacy mappings conservative |
| Automatic threshold | Fresh quota collector and actually delivered trusted hooks/wrapper; default 20% or explicit task-local baseline |
| Remaining percentage | Finite 0–100 initial task baseline under the current owner; post-stop percent/ten/exhaustion grants require reviewed resume; numeric zero still stops at zero |
| Inspection | Nested repositories reported as unsaved boundaries; separate preservation or explicit exclusion required |
| Collector | Quota refresh independent of optional transfer failures; preservation errors remain visible and affected dispatch stays blocked |
| Maintenance | Strict parsed commands for native Bash and exec_command names; no ordinary/chained shell execution exemption |
| Readiness | Notification-only ticket using existing collector, blocking resets and fresh readings; no automatic resume |
| Native notification | macOS adapter supplied; display, permission and timing require actual host evidence; Windows/Linux need a reviewed notifier |
| Cross-device | Source history, private checkpoint bundle, external exports and independent credentials/review/ownership; local grants/policies do not transfer |
| Optional router | Separately authorized qualified assignment, tools/privacy class, resources and ownership |

Consult the versioned validation report for executed tests and supported native
checks. Isolated fixtures and manual hook callbacks establish runtime behavior,
not native event delivery. Prior fresh-context exercises, CI platforms and host
reports are historical unless repeated for this version. No claim is made here
that native 20%→custom-percentage→exhaustion transitions, notification display,
exact wake timing, every host or a second physical device have been verified.

Enrollment cannot reconstruct conversation state or guarantee a final save after
hard exhaustion. Configurations and scheduler files alone do not prove delivery.
Chat isolation is a routing boundary; local Git ownership coordinates cooperating
runtimes in one common directory, not arbitrary editors or laptops. Percent
allowance does not predict exact remaining work. Account allowance, API cost and
context capacity remain distinct, and unknown measurements stay unknown.
